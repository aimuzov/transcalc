# Формула доставки между городами

Проверено 14 ноября 2026 года. Восстановлена схема обычной автоперевозки: ставка направленной пары регионов, округлённый дорожный пробег и отдельные ставки городских пар.
Исходный PHP-код недоступен, поэтому это проверенная модель наблюдаемого поведения.

## Базовая цена

```text
D = 100 × ceil(дорожное_расстояние_км / 100)
R = справочник[регион_отправления][регион_назначения]
B0 = max(35 000, D × R)
B = индивидуальная_ставка_городской_пары, если она задана; иначе B0
```

B: стоимость отдельной машины 20 т с НДС. R: рубли за километр.
Расстояние направленное: обратный путь может отличаться.
Наличие обслуживания проверяется отдельно: ответ `not_served` не заменяется ценой из формулы.

Наблюдаемые примеры R:

| Откуда                | Куда                  | ₽/км |
| --------------------- | --------------------- | ---: |
| Самарская область     | Свердловская область  |  147 |
| Свердловская область  | Самарская область     |   79 |
| Татарстан             | Свердловская область  |  137 |
| Свердловская область  | Татарстан             |   99 |
| Нижегородская область | Татарстан             |  184 |
| Татарстан             | Нижегородская область |   93 |
| Ростовская область    | Краснодарский край    |  158 |
| Краснодарский край    | Ростовская область    |  210 |
| Приморский край       | Хабаровский край      |  225 |
| Хабаровский край      | Приморский край       |  200 |

Ставки не сводятся к одному коэффициенту города. Проверка четырёх маршрутов и направленных циклов опровергла простые аддитивные и мультипликативные модели.
Например, для Самары => Екатеринбурга => Новосибирска произведение отношений прямых и обратных ставок равно 1,9855, хотя модель независимых городских коэффициентов требует 1.

## Примеры базы и исключений

Самара => Екатеринбург: 993 км, D=1000, R=147, B=147000 ₽.
Тольятти => Екатеринбург: 1033 км, D=1100, тот же R=147, B=161700 ₽.
Казань => Самара: D=400, R=79, произведение 31600; применяется минимум 35000 ₽.

Петербург => Бердск: 3939 км, D=4000, R=106, B=424000 ₽.
Всеволожск => Новосибирск: 3924 км, те же регионы, D=4000 и R=106, B=424000 ₽.
Петербург => Новосибирск: D=4000 и R=106, но опубликованная B=480000 ₽. Формуле требуется исключение конкретной городской пары.

## Вес машины

`ceil100(x) = 100 × ceil(x / 100)`.

```text
Цена_машины = ceil100(B × k)
```

| Верхняя граница веса, кг |    k |
| ------------------------ | ---: |
| 1500                     | 0.44 |
| 3000                     | 0.53 |
| 5000                     | 0.66 |
| 7000                     | 0.75 |
| 10000                    | 0.88 |
| 20000                    |    1 |

## Сборный груз и НДС

```text
P = B × вес_кг / 10 000
Сборный_до_предела = max(12 000, ceil100(P × q(P)))
Сборный = min(Сборный_до_предела, 100 × floor(Цена_машины × 0.85 / 100))
Цена_без_НДС = round(Цена_с_НДС / 1.22)
```

| P            | q(P) |
| ------------ | ---: |
| менее 20000  | 1.40 |
| менее 40000  | 1.19 |
| менее 60000  | 1.12 |
| менее 100000 | 1.05 |
| менее 140000 | 0.98 |
| остальные    | 0.70 |

Дробные килограммы сервер отбрасывает. Обычный диапазон от 500 до 20000 кг; сборный доступен до 11000 кг включительно.
На границах скидок цена может уменьшаться при увеличении веса: это поведение исходного калькулятора.
Контейнеры используют отдельные ставки и в эту формулу не входят.

## Объём проверки

В анализе 200 уникальных комбинаций маршрута и веса. Для 98 маршрутов сохранён ответ на 20 т.
Они охватывают 49 направленных пар регионов; у 24 пар есть несколько разных городских маршрутов, ставка внутри каждой такой группы совпала.
Обычная B0 совпала на 85 маршрутах, ещё 13 требуют отдельных ставок. Все 13 сохранены как отклонения, а не скрыты подгонкой.

В 11 региональных прайсах собрано 3853 строки: 3756 уникальных направленных пар.
Все 15412 опубликованных цен совпали с весовыми множителями 0.44, 0.66, 0.88 и 1 и округлением вверх до сотен.
Это проверка весовых колонок прайса, а не доказательство базовой формулы на всех 3756 направлениях.
Шесть дополнительных контролей проверяют цепочку от региональной ставки до итоговых цен, включая другие веса и Самару => Крымск в обе стороны.

## Откуда берутся ставки

Прайсы опубликованы на региональных поддоменах, например [Самара](https://samara.datrans.ru/gruzoperevozki-po-rossii/) и [Казань](https://kazan.datrans.ru/gruzoperevozki-po-rossii/).
Для каждого значения сохранён URL. Результаты калькулятора взяты из объекта DATA в HTML `/calc/`.

Если несколько обычных баз одного регионального направления равны `R × 100 × n`, НОД значений `B/100` даёт кандидата R или его кратное.
Такой кандидат требует отдельной проверки: индивидуальные тарифы и общий делитель n могут исказить вывод.
Регион берётся из ответа калькулятора. Autocomplete ограничен семью результатами и у двух казахстанских городов выдаёт конфликтующие регионы; эти случаи сохранены отдельно.

## Границы результата

Для нового города нужны дорожное расстояние и известная ставка его региональной пары. Одних названий городов и веса недостаточно.
Полного исходного справочника R и полного списка исключений пока нет. Отсутствующая ставка не заменяется оценкой.
Эквивалентность модели проверена на сохранённой выборке; неизменность правил во времени не доказана.
Текущий сайт продолжает использовать опубликованный снимок направлений Москвы, это исследование расширяет понимание алгоритма.

## Воспроизведение

```sh
npm run test:routes
python3 scripts/route_formula.py --check
python3 scripts/collect_route_quotes.py quotes data/route-formula/cases.json
python3 scripts/collect_route_quotes.py tariffs samara kazan abakan engels vyksa ekaterinburg novosibirsk nizhniy-novgorod ufa vladivostok habarovsk
```

`data/route-formula/analysis.json`: реестр наблюдаемых ставок, проверенные маршруты, отклонения B и недоступные направления.
`data/route-formula/quotes/`: исходные ответы калькулятора.
`data/route-formula/published-rates.json`: извлечённые цены и URL прайсов.
`scripts/route_formula.py`: расчёт базы и повторяемый анализ.
Сбор использует кеш и последовательные запросы с паузой не меньше секунды. HTML кешируется за пределами репозитория.
